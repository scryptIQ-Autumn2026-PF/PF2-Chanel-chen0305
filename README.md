## :computer: Where to Code:

- **GitHub Codespaces**: In order to practice coding yourself, and complete the assignment, you can use a GitHub Codespace. Click the green **Code** button at the top of your lesson repository, select the **Codespaces** tab, and click the green **Create codespace on main** button, and a new Codespace will auto-create. Please be patient, and ensure you have a fast and stable internet connection to use this. We recommend manually saving your work, and following the [Course Handbook](https://scryptiq-autumn2026-pf.github.io/Python-Fundamentals/HB/assignment-submission.html) instructions to submit assignments completed in a Codespace. For more information on Codespaces, please see our [Python Orientation reference materials, here.](https://scryptiq-autumn2026-pf.github.io/Python-Fundamentals/PF0/course-setup.html#github---codespaces)

- **Coding in an IDE**: As an alternative, if you wish to code locally, and push your work back to your lesson repository on GitHub, you can do so *via* an Integrated Developer Environment (IDE) of your choosing. We recommend [**Microsoft Visual Studio Code**](https://code.visualstudio.com/), as it has extensions that allow you to integrate easily with GitHub. If you're setting up for the first time, we recommend installing the [Anaconda distribution of Python](https://scryptiq-autumn2026-pf.github.io/Python-Fundamentals/PF0/installing-python.html#anaconda), first. Once you have done this, you can find more information on how to set up VS Code in the relevant sections of our [Python Orientation reference materials, here.](https://scryptiq-autumn2026-pf.github.io/Python-Fundamentals/PF0/course-setup.html#visual-studio-code--vs-code)

## :rocket: How to Submit Your Assignment:

- **For the final submission to be marked** you can commit and push back to this repository as many times as you like. However, when you want your assignment to be marked please make sure your commit message *contains* this exact phrase:

  > **"assignment completed"**

- See the [Course Handbook](https://scryptiq-autumn2026-pf.github.io/Python-Fundamentals/HB/introduction.html) for the details on the submission.

- **To confirm it worked:** Wait a minute and then refresh your repository's page on GitHub. You should see a green tick next to your latest commit with the above commit message
